# CLAUDE.md — правила проекта «Рубеж»

Игра на **Godot 4.5** (GDScript), 2D вид сверху, живой мир. Дизайн и план — в `DESIGN.md`,
читай его перед работой. Текущий шаг — первый неотмеченный пункт в «Дорожной карте».

## Архитектура
- `scripts/sim/` — **вся логика мира**. Только `RefCounted`, никаких нод и графики.
  `World` хранит состояние и крутит тики; системы — статические модули:
  `NpcAI`, `Combat`, `Economy`, `Rumors`, `FactionAI`, `Scenarios`, `Dialogue`, `WorldGen`.
- `scripts/game/` — ввод, камера, отрисовка (`WorldView`), интерфейс (`Hud`, `DialogueUI`).
  Только читает `World` и вызывает его методы. Логику мира сюда не класть.
- `data/*.json` — весь контент: фракции, поселения, роли, черты, фразы, товары.
  Новый контент = новые данные, не новый код.
- Любое событие мира — **факт** через `World.add_fact()`. На факты реагируют NPC
  (`NpcAI.on_learn`) и фракции (`FactionAI._react`). Не делай обходных путей.
- Состояние сохраняется через `to_dict()`/`from_dict()`. Новое поле класса добавляй в `SAVE_KEYS`.

## Проверка (обязательно после каждого изменения)
```bash
G=godot   # путь к Godot 4.5
$G --headless --path . --import                      # после добавления новых class_name
$G --headless --path . --script res://tests/test_sim.gd   # должно быть «ВСЕ ТЕСТЫ ПРОЙДЕНЫ»
# скриншот без окна (Linux: через xvfb-run):
$G --path . -- --scenario=soldier --seed=7 --ticks=200 --screenshot=/tmp/shot.png
#   флаги: --scenario=slave|officer|crash|soldier  --godview  --talk  --zoom=1.5
```
Новую механику покрывай проверкой в `tests/` (для ИИ — тест-сценарий с утверждениями).

## Подводные камни GDScript
- `var x := dict["k"]` или `:= array[i]` — ошибка «Cannot infer the type». Пиши тип явно:
  `var x: int = dict["k"]`.
- Числа из JSON приходят как `float` — оборачивай в `int()` где нужно.
- `String.join()` принимает `PackedStringArray(...)`.
- Не меняй словарь, пока идёшь по нему циклом, — иди по `keys()`.
- Случайность только через `world.rng` (детерминизм и сохранения).

## Стиль
- Интерфейс, комментарии, коммиты — на русском. Идентификаторы — на английском.
- Комментарии короткие: зачем, а не что.
- Один пункт дорожной карты за сессию. В конце: тесты зелёные, скриншот проверен,
  пункт в `DESIGN.md` отмечен `[x]`, коммит.
