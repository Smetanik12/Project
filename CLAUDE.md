# CLAUDE.md — правила проекта «Рубеж»

Сначала прочитай **ЭСТАФЕТА.md** (состояние, план, как запускать), затем **docs/ТРЕБОВАНИЯ.md**
(что хочет автор, дословно) и **DESIGN.md** (замысел). Текущий шаг — первый невыполненный в
ЭСТАФЕТА.md §5.

Игра на **Godot 4.5, Forward+**, GDScript. Мир 3D под углом, персонажи 2D (HD-2D). Огромная
планета (1 тайл = 2 м, 32768×16384 тайлов) генерируется из сида, детали — лениво по чанкам 32×32.

## Архитектура
- `scripts/sim/planet/` — география (только `RefCounted`, без нод): `Planet`, `PlanetGen`,
  `ChunkGen`, `LayoutGen`, `InteriorGen`, `NameGen`, `Site`, `Chunk`. Детерминированно из сида.
- `scripts/sim2/` — симуляция v2 (будет): время, экономика без «из ниоткуда», материализация
  людей вокруг игрока, NPC, фракции, факты и слухи.
- `scripts/view/` + `shaders/` — 3D-отображение: только читает мир. `PlanetView` грузит чанки в
  рабочих потоках.
- `scripts/sim/*.gd`, `scripts/game/` — старый 2D-прототип (переносить из него диалоги, слухи,
  сценарии; потом удалить).
- `data/*.json` — контент. Новый контент = новые данные, не новый код.

## Проверка (обязательно после каждого изменения)
```bash
G=godot          # Windows (Git Bash): G=/c/Godot/Godot_v4.5-stable_win64_console.exe
tools/check.sh                                                 # синтаксис всех скриптов
"$G" --headless --path . --script res://tests/test_planet.gd   # «ВСЕ ПРОВЕРКИ ПЛАНЕТЫ ПРОЙДЕНЫ»
"$G" --path . res://scenes/explorer.tscn -- --site=rodnik --time=10 --shot=shots/rodnik.png   # и посмотреть картинку
```
PowerShell и всё про Windows — ЭСТАФЕТА.md §2.
Для каждой новой системы — тест на инварианты (пересечения, доступность, сохранение товаров,
детерминизм, скорость). Графику — проверять скриншотом глазами.

## Подводные камни
- Новый `class_name` → `"$G" --headless --path . --import`.
- Снимки и карты — только в `shots/` (там `.gdignore`, иначе Godot начнёт их импортировать).
- Концы строк — LF (`.gitattributes`); bash-скрипты с CRLF не работают.
- Не называть методы `_get`, `_set`, `_notification` и т.п. — конфликт с Object.
- `var x := arr[i]` / `dict[k]` / `[a, b][i]` — тип явно: `var x: int = ...`.
- Числа из JSON — `float`, оборачивать в `int()`.
- `extends SceneTree` при ошибке не выходит — запускать с `timeout`.
- Словари построек после генерации не менять (их читают потоки); кэши — в `Site` под `mutex`.
- Задачи `WorkerThreadPool` всегда дожидаться.
- Случайность — только от сида (`U.hash3`, `U.rnd3`, свой RNG с сидом).

## Стиль
- Интерфейс, комментарии, коммиты — на русском. Идентификаторы — на английском.
- Комментарии короткие: зачем, а не что.
- Один шаг плана за сессию. В конце: тесты зелёные, скриншоты проверены, ЭСТАФЕТА.md и
  DESIGN.md обновлены, коммит.
